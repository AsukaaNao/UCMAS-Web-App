# UCMAS App

A simple and interactive mental arithmetic practice application inspired by UCMAS. It features two exercise modes: **Blitz**, for fast-paced calculation practice, and **Listening**, for improving listening skills and mental calculation.

## Features
- **Blitz Mode:** Practice mental arithmetic through timed calculation exercises.
- **Listening Mode:** Solve calculations by listening to generated numbers without seeing them.
- **Results Tracking:** Review answers and exercise performance.
- **Customizable Exercises:** Configure exercise settings to match different practice needs.
